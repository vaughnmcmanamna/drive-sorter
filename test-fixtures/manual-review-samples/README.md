# Manual review fixtures

These short clips intentionally have no `title` or `creation_time` metadata. Use `python tools/reset_test_fixtures.py` to copy fresh working samples into `test-videos/manual-review-samples`.

- `Clip_001.mp4`: Call of Duty: Black Ops Cold War
- `Clip_002.mp4`: Call of Duty HQ
- `Clip_003.mp4`: VALORANT

The filenames are deliberately neutral so the game must be identified from the preview frame. Canonical files live here because organizing the working copies moves them out of their source directory.
