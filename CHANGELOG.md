# Changelog

Notable changes to Drive Sorter are documented here.

## 0.1.0 - 2026-09-17

Initial public release.

- Organize Game Bar clips by metadata game title and creation year.
- Review unknown clips using still-frame previews, typing, arrow keys, drag-and-drop, or buttons.
- Preview and confirm every move, avoid overwrites, and safely handle filename collisions.
- Revisit clips under `Organized/Unsorted` after restarting the app.
- Flatten organized clips, undo the latest file-moving operation, and remove confirmed empty folders.
- Run as a Windows installer, portable package, or directly from Python source.
